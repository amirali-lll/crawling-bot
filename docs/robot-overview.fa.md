# مرور ربات 🦾

این سند مروری بر اجزای سخت‌افزاری اصلی مورد استفاده در ربات خزنده هوش مصنوعی ارائه می‌دهد. هر قطعه برای عملکرد ربات ضروری است و در زیر با یک مرجع بصری نشان داده شده است.

## 0. دکمه پاور 🔘
مهم‌ترین قسمت ربات، دکمه پاور است. برای روشن و خاموش کردن ربات استفاده می‌شود. دکمه پاور در کنار ربات، در پایین محفظه باتری قرار دارد.
و مطمئن شوید که هنگام عدم استفاده از ربات، آن را خاموش کنید تا عمر باتری حفظ شود.

## 4. سروو موتورها (2 عدد) ⚙️🤖

دو سروو موتور برای کنترل حرکت پاهای ربات یا چرخ‌ها استفاده می‌شوند و به آن اجازه می‌دهند خزیده یا هدایت شود.
سروو میکرو MG90S به دلیل اندازه فشرده و گشتاور کافی، انتخاب رایجی برای این منظور است.
> **توجه:** سروو میکروهایی مانند MG90S معمولاً در محدوده 0 درجه تا 180 درجه می‌چرخند. ارسال سیگنال‌های کنترلی خارج از این محدوده ممکن است به سروو آسیب برساند یا باعث رفتار نامنظم شود.

## 7. پورت‌های مهم 🛠️

ربات دارای دو پورت ضروری است:

- **پورت Micro-USB:**  
    برای برنامه‌نویسی میکروکنترلر ESP32 و تأمین برق در طول توسعه استفاده می‌شود. این پورت را به کامپیوتر خود وصل کنید تا کد آپلود یا ربات را دیباگ کنید.

- **پورت USB Type-C:**  
    اختصاص داده شده به شارژ باتری ربات از طریق ماژول کنترل شارژ. از یک کابل USB Type-C استاندارد برای شارژ امن باتری استفاده کنید.

<img src="images/ports.jpeg" alt="پورت‌های Micro-USB و Type-C" height="300"/>

این پورت‌ها اهداف متفاوتی دارند - مطمئن شوید که از پورت صحیح برای برنامه‌نویسی یا شارژ استفاده می‌کنید تا از مشکلات سخت‌افزاری جلوگیری کنید.
